中文说明 / Note (zh-CN)
---------------------------------------------------------------------------

本目录（feature/library/src/main/res/font）下的字体文件为 Noto Serif SC：

    noto_serif_sc_subset_400.ttf
    noto_serif_sc_subset_500.ttf

1. 字体来源：Noto Serif SC，通过 npm 包 @fontsource/noto-serif-sc 5.2.9
   获取（该包分发的是上游 Noto Serif CJK SC 的 Web 字体，版权归
   Google Inc. / Adobe Systems Incorporated 所有）。
2. 本仓库**仅打包代码实际用到的字形子集**（subsets），不是完整字体。
   子集由 tmp/font/subset_final.py 使用 fontTools pyftsubset 生成：
   从仓库源码中收集实际出现的字符，取字体的 cmap 可覆盖部分，
   并做轮廓简化与坐标量化以控制体积（两档字重合计 < 1 MB）。
   未包含的字形在界面上会显示为空白或方框，属预期行为。
3. 这两份子集属于 SIL OFL 1.1 定义的 Modified Version：
   - 不以字体本身单独售卖；
   - 随本仓库一起以 OFL 1.1 分发（本文件即许可证全文）；
   - 未使用任何 Reserved Font Name 进行命名（文件名使用
     "noto_serif_sc_subset_*" 前缀，仅用于说明其来源与子集属性）；
   - 版权声明与许可证全文见上，保持完整不修改。
4. 本字体可用于渲染任意文档，且该文档不受 OFL 约束。

若需完整字体或需要更多字形覆盖，请直接从上游 Noto Serif SC 获取。
